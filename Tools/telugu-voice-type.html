తెలుగు స్పీచ్ టు టెక్స్ట్

Chrome తెలుగు రికగ్నైజర్ (te-IN) — speechtyping.com వాడే అదే ఇంజన్. మైక్ నొక్కి, స్పష్టంగా మాట్లాడండి.

మైక్ నొక్కండి, ఆపై తెలుగులో మాట్లాడండి.

Google Chrome (లేదా Chromium) + మైక్ + ఇంటర్నెట్ కావాలి. GitHub Pages / HTTPS లో మైక్ పని చేస్తుంది. డ్రాఫ్ట్ ఈ బ్రౌజర్‌లోనే సేవ్ అవుతుంది; మరొక కంప్యూటర్‌కి తీసుకెళ్లాలంటే Download .txt వాడండి.
